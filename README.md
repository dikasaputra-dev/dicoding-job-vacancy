# Dicoding Job Vacancy Technical Test

System built for Dicoding Product Engineer Intern Technical Assessment.

The application allow recruiters to manage job vacancies and allows job seekers to search vacancies by title and view their details

## Tech Stack

### Backend

- Laravel
- PHP
- MySql
- PHPUnit or Pest

### Frontend

- Next.js
- TypeScript
- Tailwind CSS
- TanStack Query
- React Hook Form
- Zod
- Playwright

## Main Features

### Mandatory

- Create a vacancy
- List available vacancies
- Search vacancies by title
- View vacancy details
- Backend unit testing
- Backend integration testing
- Frontend end-to-end testing

### Additional

- Update a vacancy
- Delete a vacancy
- Recruiter vacancy dashboard
- Responsive user interface
- Loading, empty, and error states
